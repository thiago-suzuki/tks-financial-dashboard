## 🚀 Tecnologias
- [TypeScript](https://www.typescriptlang.org/) > Linguagem principal da aplicação
- [NextJS](https://nextjs.org/) > Framework React para criação de layout
- [TailwindCSS](https://tailwindcss.com/) > Extensão para estilização de páginas no NextJS
- [Shadcn](https://ui-v4.shadcn.com/) > Biblioteca de componentes para NextJS
- [Lucide React](https://lucide.dev/) > Biblioteca de ícones
- [Next Intl](https://next-intl.dev/) > Biblioteca para tradução de textos
- [Recharts](https://recharts.org/en-US) > Biblioteca para gráficos
<br /><br />

## 💻 Executando o Projeto

#### Passo 1 - Configure as ferramentas necessárias:
- [Node.js](https://nodejs.org/en/) (Versão 22)

#### Passo 2 - Instale as dependências:
```bash
$ npm install
```

#### Passo 3 - Configure o arquivo .env (Digite qualquer e-mail e senha):

```bash
NEXT_PUBLIC_LOGIN_USER=""
NEXT_PUBLIC_LOGIN_PASSWORD=""
```

#### Passo 4 - Execute o projeto:
```bash
# development
$ npm run dev
```
